Расшифровка видео

Вставьте ссылку на ролик из Instagram или выберите видео с компьютера.

Распознавание и скачивание идут на вашем компьютере. Первый запуск загружает модель распознавания, это может занять несколько минут. Для приватных роликов приложение может использовать вход в Instagram из браузера, если его настроить.
